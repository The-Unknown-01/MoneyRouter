# 单线程界面与三概念业务流程

## 用户路径

`注册/登录 → Eino Agent 自然对话 → 确认 Income / Outcome / Feature → 可选分类开销、CSV 或跳过 → 方案 → 可选复盘或答疑`

- `/` 按账号数据跳转到当前步骤；不再渲染仪表盘。
- 顶部仅有三个进度标记和当前账号。进度标记不承担全局跳转。
- 画像 Agent 通过多轮自然对话收集明确事实，自主决定追问；用户可在同页核对或编辑三项摘要。Income 包括工资、奖学金、生活费等每月可用资金；Outcome 是大致月支出；Feature 是个人阶段、责任、目标与风险特点。
- 分类月开销是默认录入方式。跳过入口在开销页首屏，CSV 通过小按钮展开。旧有逐笔账单放在详情中保留编辑能力。
- 跳过账本且 Outcome 已知时，方案采用对话中的估计并标注数据来源。Outcome 完全未知时，先显示不含投资金额的临时建议，引导补一个大致数字。
- 方案金额由服务端可复算算法生成和校验；Agent 调用工具核对并记录过程，展示说明以校验后的金额为准。
- 方案页按月收入流向、预备金、可配置资金、Agent 解释的顺序阅读。复盘和答疑在方案后提供可选入口，返回方案即可继续。
- 已完成的用户可以从方案回到账本补录，也可回到画像修改。重新生成方案时保留版本记录。

## 路由约束与验收

- 未确认画像时，账本及之后的业务路由返回画像步骤。
- 已确认画像但尚未选择账本状态且没有旧账单时，方案返回可选开销步骤。
- 分类月开销已保存、账本已跳过，或已有逐笔账单时，进入方案。
- 未保存方案时，复盘和答疑返回方案步骤。
- 直接访问 `/` 与登录后的跳转一致；两个账号按各自进度独立跳转。
- 桌面与手机宽度均为单列主内容；无侧栏、底部全局导航或仪表盘卡片矩阵。
- 功能回归覆盖学生生活费、对话提取、分类开销、CSV、跳过、未知 Outcome 临时建议、方案生成和跨账号隔离。

## 动效约定

- 每次进入步骤或可选分支时，主内容短距离淡入；离开页面时轻微淡出。登录、注册、筛选和返回操作沿用同一节奏。
- 画像问答、分类开销保存、账本跳过/导入、方案生成/重算、复盘筛选与答疑均有可见的操作反馈；等待模型或导入时显示不宣称具体完成百分比的进度动画。
- 三项摘要、分类输入、CSV 展开与方案资金分配逐项呈现有局部过渡。动效使用透明度与位移，避免大面积复杂计算。
- 遵循 `prefers-reduced-motion`；关闭动效时流程和反馈文字仍完整可用。
